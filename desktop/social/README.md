# Perfiles públicos 1.3.0

En el SQL Editor del proyecto Supabase de Ranked Pro, ejecutar `profile-appearance.sql` después de la migración social 1.1.0. La operación sustituye únicamente la función de publicación de apariencia y conserva los perfiles existentes.

Después, cada editor debe abrir Social y pulsar Actualizar para publicar país, XP, frase, banner, decoración, colores y efectos de borde. Los GIF personalizados se conservan localmente; el avatar público se publica como imagen PNG.

Las cifras de XP de apariencia son declaradas por el cliente y no cambian la clasificación del servidor, que sigue ordenada por tiempo de edición.
